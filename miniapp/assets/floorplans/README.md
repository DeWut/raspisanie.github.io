# Campus floor plan image assets

The viewer expects eight source images in this directory. They were supplied by the project owner on 2026-11-27 and packaged separately as `campus-floorplans-for-repository.zip`.

- `building-1-floor-1.webp` through `building-1-floor-4.webp`: photographed room layouts for building No. 1, letter У.
- `building-2-evac-floor-1.webp` through `building-2-evac-floor-4.webp`: photographed evacuation plans for building No. 2, letter Б.

The second set is evacuation information, not a room-layout plan. During an emergency, follow current on-site signage and university staff instructions.
