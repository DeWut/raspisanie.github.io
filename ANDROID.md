# SPBFTUIT для Android

Android-версия использует существующий интерфейс `miniapp/` внутри Capacitor WebView. Отдельно переписывать экран расписания не требуется.

## Что входит в APK

- интерфейс расписания;
- выбор учебной группы и локальное сохранение выбора;
- календарь, просмотр недели и карточки занятий;
- локальная копия `data/groups.json` и файлов расписания, доступная без сети после установки APK;
- ссылки на Telegram и сайт университета;
- локальные Android-уведомления за 10 минут до пары (по расписанию и чётности недели), на следующие 14 дней;
- повторная синхронизация напоминаний при запуске приложения и смене группы.

Для обновления расписания и загрузки новых данных потребуется подключение к интернету. В APK включается снимок файлов `data/` на момент сборки.

## Получение APK

1. Открой GitHub → Actions → **Build Android APK**.
2. Нажми **Run workflow** для ветки `feature/smart-campus-step-1`.
3. После успешной сборки открой завершённый запуск.
4. В разделе Artifacts скачай `SPBFTUIT-android-debug` и установи APK на Android.

Это debug-сборка для тестирования, не подписанный релиз для Google Play. Для публикации потребуется отдельный release keystore и защищённые GitHub Secrets.

## Локальная сборка

Нужны Node.js 22, JDK 21 и Android SDK. Затем:

```bash
npm install
npm run mobile:prepare
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

## Ограничения первой версии

Это оболочка существующего веб-интерфейса, а не полностью нативная перепись. Android push-уведомления, фоновые напоминания, системный календарь и авторизация через аккаунт приложения будут добавляться отдельно. Telegram Web App bridge доступен только при запуске внутри Telegram.
