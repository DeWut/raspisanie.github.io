# Уточнение кабинетов для поэтажных планов

Заполняйте таблицу `floorplan-room-corrections.csv` и отправьте её обратно в чат.

- Одна строка — одно помещение.
- В поле «Корпус» укажите 1 или 2.
- В поле «Этаж» укажите номер этажа.
- В «Номер кабинета» перепишите номер с таблички или плана.
- «Название / назначение» — например, кафедра, лаборатория, аудитория, библиотека.
- «Крыло или ориентир» — например, северное крыло, рядом с лестницей, напротив аудитории 215.
- Если поле неизвестно, оставьте его пустым. Не нужно угадывать.
- Для исправления существующей записи добавьте строку с правильными данными и напишите в комментарии «исправить».

Файл предназначен для уточнения данных навигации. Геометрию стен и дверей можно будет корректировать отдельно по фото или обмерному плану.
