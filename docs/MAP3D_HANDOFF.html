Состояние работы

Геометрия проверена 7 автотестами Node.js. Интеграция подключает страницу к основному приложению через один iframe; реальная отрисовка на Android и Telegram WebView всё ещё требует ручной проверки после публикации.

Процедурная карта MapLibre становится единственным пользовательским экраном карты кампуса. Яндекс и 2ГИС не загружаются в приложение и не требуют API-ключей; спутниковая подложка — Esri World Imagery, схема и 3D-геометрия строятся из локальных данных OSM.

Запуск и проверка

  1. Запустить статический сервер из корня репозитория, например python3 -m http.server 8080.
  2. Открыть http://localhost:8080/miniapp/map3d.html либо открыть карту из приложения через кнопку карты. Через file:// данные не загрузятся.
  3. Режим схемы без внешних тайлов: map3d.html?mode=scheme.
  4. Автотесты: node --test tests/map3d-geometry.test.js (нужен Node 18+; указывать файл, а не папку).
  5. Проверить: наклон двумя пальцами, клик по корпусам 1–4, фото Wikimedia и сведения главного корпуса, кнопки «Тени», «Деревья», «Окна», «Облёт», «Сброс», окна при zoom ≥ 17.2.

Что проверено: синтаксис (node --check) и 7 автотестов (классификация высот, связь со справочником, замкнутые кольца без NaN, двор не закрывается крышей, лимит окон, случайные и вырожденные полигоны). Что не проверено: реальная отрисовка на Android Chrome и Telegram WebView, а также результат GitHub Actions.

Архитектура

  1. map3d.js загружает campus-park-scene.json и campus.json (пути ../data/, ./data/, data/ по очереди).
  2. Основное приложение показывает эту страницу в одном полноразмерном iframe; отдельные переключатели Яндекса и 2ГИС удалены из пользовательского интерфейса. Ключи карт не загружаются.
  3. Map3D.buildScene(scene, campus) возвращает {ground, solid, windows, trees, shadows, highlight, index, stats}.
  4. Каждый список записывается в свой GeoJSON-источник MapLibre через setData.
  5. Все детали зданий лежат в одном источнике solid как отдельные fill-extrusion-фичи с полями col (цвет), z0 (низ, м), z1 (верх, м). Один слой bld рисует их все.
  6. Клик читает pid фичи и берёт данные из scene.index[pid]; в campus.json здание ищется по номеру или OSM id.

Из чего строится здание

ЧастьКак строится
ЦокольКонтур, увеличенный на 0,12 м, высота 0–1 м, тёмный оттенок стены.
СтеныИсходный контур от 0 до высоты h.
ПерекрытияТонкие пояса (0,3 м) на границах этажей, контур +0,1 м.
ОкнаОтдельные тёмные «коробки» 1,15 м шириной с шагом 3 м вдоль каждой стены, на каждом этаже. Бюджет по умолчанию 30 000 штук, сначала корпуса из справочника, потом по убыванию площади.
Карниз и крышаПлоская: карниз + утопленная плита. Для тегов roof:shape hipped/gabled/pyramidal и выпуклого контура без двора: четыре ступени, уменьшающиеся к центру.
Тень на землеВыпуклая оболочка контура и его сдвига (солнце с азимута 215°), для невыпуклых зданий только сдвинутый контур. Длина тени 0,55 от высоты, не более 22 м.

Смещения контуров делаются анизотропным масштабированием по ограничивающему прямоугольнику (offsetRing). Это достаточно для долей метра, но не настоящий offset полигона.

Данные

Схема campus-park-scene.json (FeatureCollection, создаётся scripts/build-campus-park-scene.py):

properties.kindЧто используется
buildingosmId, heightKnown, heightMeters, heightSource, levels, osmBuilding, styleColor, cladding, roofShape, roofMaterial, roofColor, campusNumber, sourceUrl, name
tree-canopy / tree-trunkfoliageColor, полигон кроны (12 точек)
green-area, water, park-boundary, pathПередаются в слой земли как есть (areaType для зелени).

Классификация высоты: heightKnown и источник «OSM height» — known; источник со словом «levels»/«estimate» — levels; иначе assumed (9 м, для гаражей и сараев 3,2 м). Статус виден в карточке здания и в строке статистики.

Слои карты (снизу вверх)

bg · sat (Esri, по умолчанию) · park · green · water · path-casing · path · shadow · bld · win (minzoom 17.2) · tree · hl (подсветка выбранного).

В режиме «Спутник» слои земли скрыты, виден только растр Esri. В режиме «Схема» наоборот.

Освещение: map.setLight и map.setSky вызываются в try/catch, потому что API зависит от версии MapLibre. Если небо не поддерживается, остаётся CSS-градиент за холстом.

Что реально, а что стилизация

Нельзя называть эту карту фотореалистичной. Реальны контуры и высоты (где они есть в OSM). Окна, карнизы, цоколи, цвета стен, ступенчатые крыши и кроны деревьев сгенерированы процедурно. Цвет стены берётся из OSM только при явном теге, иначе выбирается детерминированно из тёплой палитры по id здания.
  • Рельефа нет: кампус плоский, а карта высот не подключалась.
  • У многих зданий нет высоты в OSM — они показаны условно. Улучшить можно тегами height/building:levels в OpenStreetMap.
  • Реальных фасадов и крыш нет. Настоящий фотореал возможен только из своих данных: аэрофотосъёмка с дрона, ортофото, фотограмметрическая модель (3D Tiles или glTF).
  • Ступенчатая крыша не передаёт конёк и вальмы, это упрощение.
  • Тени наложены полупрозрачными полигонами, при пересечении они темнее. Это допустимый артефакт.

Что делать дальше

  1. Открыть страницу на реальных данных и подправить палитру, толщину окон и тени. Это самый важный шаг: внешний вид не проверялся глазами.
  2. Определить версию MapLibre в vendor и проверить setLight/setSky на ней.
  3. Протестировать на Android Chrome и в Telegram Mini App; при низкой частоте кадров уменьшить maxWindows (параметр buildScene).
  4. Добавить ссылку на map3d.html в интерфейс мини-приложения (miniapp/index.html, диалог карты). Сейчас страница отдельная.
  5. Добавить map3d*.js и map3d.html в кэш Service Worker и в проверку синтаксиса CI.
  6. Подключить расширенную выгрузку зданий (scripts/update-campus-osm.py), когда её закоммитят.
  7. Опционально: поднять реальные данные высот, ортофото или модель; поддержать building:part и roof:height там, где они размечены.

Лицензии и источники

  • Данные зданий, деревьев и дорожек: © OpenStreetMap contributors, ODbL 1.0. Атрибуция выводится в карте.
  • Спутниковая подложка: Esri World Imagery (без ключа). Условия использования нужно проверить перед публикацией; атрибуция Esri выводится картой. Режим ?mode=scheme не обращается к внешним тайлам.
  • MapLibre GL JS лежит в miniapp/vendor вместе с файлом лицензии.
  • Не скачивать, не сшивать и не использовать как текстуры снимки Yandex, Google и 2GIS.

Безопасность и ключи

В miniapp/campus-map-config.js на ветке feature/campus-map-photorealism лежат ключи Yandex и 2GIS, а репозиторий публичный. Ключи нужно ограничить по домену (HTTP referrer) или перевыпустить. Новая карта ключей не использует.
