# Развёртывание SPBFTUIT backend и подключение Mini App

## Текущее состояние инфраструктуры

Backend — отдельное приложение на Rust/Axum. Он подключается к Neon PostgreSQL и применяет SQLx migrations при старте. В локальном режиме Telegram работает через long polling; на Render Free автоматически включается webhook-режим, чтобы входящие сообщения могли разбудить спящий бесплатный экземпляр. GitHub Pages публикует только статический сайт и Mini App.

Для публичного backend подготовлен Render Blueprint в корне репозитория (`render.yaml`). Используется обычный Rust runtime, без Docker и без Render SDK. Локальный запуск через Cargo по-прежнему поддерживается.

Render Free официально позволяет начать без банковской карты, но экземпляр засыпает после 15 минут без входящих запросов и может просыпаться около минуты. В проекте поэтому включён Telegram webhook, а не long polling. Это снижает требования к постоянной активности, но не гарантирует точное время фоновых напоминаний, пока экземпляр спит. Render Free также ограничен 750 часами экземпляра в месяц; Neon остаётся отдельной базой данных. См. `docs/free-deployment.md`.

## Локальный запуск backend

1. Установи Rust stable и PostgreSQL-клиент не требуется: база уже размещена в Neon.
2. Скопируй `backend/.env.example` в `backend/.env` и заполни реальные значения локально. Не коммить `.env`.
3. Укажи pooled Neon URL в `DATABASE_URL`. Для миграций лучше задать direct URL без `-pooler` в `DATABASE_URL_UNPOOLED`.
4. Укажи `TELOXIDE_TOKEN`, `ADMIN_TELEGRAM_ID`, `WEBAPP_URL`, `CORS_ALLOWED_ORIGINS` и `PORT=8080`. Не включай `DEV_BYPASS_AUTH` для реального Telegram-тестирования.
5. Из каталога `backend` выполни:

```powershell
cargo check --all-targets
cargo test --all-targets
cargo run
```

При старте backend применяет SQLx migrations, проверяет соединение с Neon и запускает фоновую синхронизацию расписания. Если заданы `TELEGRAM_WEBHOOK_SECRET` и `RENDER_EXTERNAL_URL` (или `TELEGRAM_WEBHOOK_URL`), бот регистрирует webhook; иначе используется прежний Telegram long polling. Проверка API: `GET http://127.0.0.1:8080/health`. При недоступной базе ожидается HTTP 503.

## Подключение Mini App к локальному backend

GitHub Pages отдаёт только статические файлы. Rust/Axum backend и Telegram long polling должны работать отдельно. Для текущего локального этапа не нужно коммитить адрес туннеля в репозиторий: Mini App умеет сохранить его локально в Telegram WebView.

1. В первом PowerShell из каталога `backend` запусти backend:

```powershell
cargo run
```

2. Во втором PowerShell открой HTTPS-туннель к локальному API:

```powershell
cloudflared tunnel --url http://127.0.0.1:8080
```

Cloudflare выдаст временный адрес вида `https://....trycloudflare.com`. В Mini App открой «Настройки» → блок «Подключение backend», вставь только этот origin и нажми «Подключить». Mini App проверит `/health`, сохранит адрес в локальном хранилище Telegram WebView и перезагрузится. Адрес не содержит секретов и не меняет код сайта.

Временный Quick Tunnel предназначен для разработки: адрес меняется после перезапуска туннеля, работает только пока запущена команда `cloudflared`, а локальный backend должен оставаться запущенным. Не оставляй на компьютере секреты в общедоступном чате и выключай туннель после теста. Для пользователей сайта такой локальный URL не подходит; для общего доступа понадобится постоянный публичный HTTPS-хост backend.

Когда появится постоянный HTTPS origin, его можно задать для всех пользователей в `miniapp/campus-map-config.js` как `window.SMART_CAMPUS_API_URL`. Указывай origin без `/api`, пути и завершающего слеша. Не записывай токены и пароль Neon в этот файл.

CORS должен содержать origin сайта, например `https://dewut.github.io` — без пути репозитория и `/miniapp/`. Telegram Mini App должен открываться по HTTPS. Backend проверяет подписанный `Telegram.WebApp.initData`; не передавай Telegram ID как замену проверке подписи.

## Проверки после локального запуска

### HTTP и база
- Открой `http://127.0.0.1:8080/health`.
- При доступной Neon ожидается JSON со `status: "ok"` и `database: "ok"`.
- При недоступной Neon ожидается HTTP 503, а не ложный успешный health check.
- В логах проверь успешное применение миграций и запуск API.

### Mini App → Neon → Telegram bot
- Открой Mini App из личного чата бота через HTTPS URL.
- В «Настройки → Личное» измени интервал напоминания, сохрани, перезапусти Mini App и проверь загрузку значения.
- Для теста включи дайджест только на тестовом аккаунте и проверь часовой пояс Москва.

### Групповые настройки и права
- Добавь бота в тестовую Telegram-группу и назначь администратором.
- Выполни `/setgroup` и `/chat_settings`, чтобы backend получил актуальные сведения о чате.
- В Mini App проверь, что изменять настройки могут только пользователи, чьи права подтверждены через Telegram.
- Проверь независимую доставку расписания, дайджеста и уведомлений об изменениях, а также настройки ДЗ, экзаменов, мероприятий и контекстного помощника.
- Включение контекста требует отдельного информированного согласия участников; согласие не должно сбрасываться при сохранении других настроек.

### Реальная доставка уведомлений
- В Mini App отправь тестовое уведомление себе и проверь запись `manual_test / sent`.
- Проверь heartbeat фонового цикла и отсутствие ошибок в логах.
- Для групповых уведомлений создай отдельные тестовые настройки с ближайшим временем доставки.

## Что пока требует Telegram-чата

Некоторые действия требуют исходного Telegram-сообщения или Telegram-вложения: модерация ответом на сообщение, загрузка/прикрепление файлов к ДЗ, native poll и часть операций управления участниками. Для них Mini App направляет пользователя в Telegram; это не должно имитироваться фиктивными кнопками.

## Контекстный помощник

Помощник Mini App использует локальный классификатор намерений и функции проекта: расписание, следующую пару, домашние задания, дедлайны, преподавателей и аудитории. Он не отправляет запросы внешним AI API. В Neon сохраняются только распознанные учебные обмены, максимум 24 записи на пользователя и 7 дней хранения. Обычные вопросы и личные сообщения без учебного намерения в историю не записываются.
