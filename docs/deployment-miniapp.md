# Развёртывание SPBFTUIT backend и подключение Mini App

## Текущее состояние инфраструктуры

Backend — отдельное приложение на Rust/Axum. Он запускает HTTP API и Telegram long-polling worker в одном процессе, подключается к Neon PostgreSQL и применяет SQLx migrations при старте. GitHub Pages публикует только статический сайт и Mini App; сам по себе Pages не запускает Rust backend и Telegram-бота.

Проект сейчас рассчитан на локальные тесты. Render не является обязательной частью архитектуры: Blueprint-конфигурация Render удалена, а код backend не использует SDK или API Render. Dockerfile оставлен только как необязательный способ сборки; локальный запуск через Cargo не требует Docker.

Постоянный публичный хостинг пока не выбран. До выбора провайдера не создавай сервис и не привязывай банковскую карту. Для будущего размещения проверяем отдельно: отсутствие обязательной банковской карты на старте, поддержку постоянно работающего Rust-процесса, исходящих HTTPS-запросов к Telegram и ЕИОС, TCP-доступа к Neon, переменных окружения, HTTPS и стоимость после окончания бесплатного периода. Бесплатные тарифы могут засыпать или иметь лимиты — для Telegram long polling это нужно учитывать.

## Локальный запуск backend

1. Установи Rust stable и PostgreSQL-клиент не требуется: база уже размещена в Neon.
2. Скопируй `backend/.env.example` в `backend/.env` и заполни реальные значения локально. Не коммить `.env`.
3. Укажи pooled Neon URL в `DATABASE_URL`. Для миграций лучше задать direct URL без `-pooler` в `DATABASE_URL_UNPOOLED`.
4. Укажи `TELOXIDE_TOKEN`, `ADMIN_TELEGRAM_ID`, `WEBAPP_URL`, `CORS_ALLOWED_ORIGINS` и `PORT=8080`. Не включай `DEV_BYPASS_AUTH` для реального Telegram-тестирования.
5. Из каталога `backend` выполни:

```powershell
cargo check --all-targets
cargo test --all-targets
cargo run
```

При старте backend применяет новые SQLx migrations, проверяет соединение с Neon, запускает фоновую синхронизацию расписания и Telegram polling, если задан токен. Проверка API: `GET http://127.0.0.1:8080/health`. При недоступной базе ожидается HTTP 503.

## Подключение Mini App к backend

Открой `miniapp/campus-map-config.js` и укажи origin backend (без `/api` и завершающего слеша) в `window.SMART_CAMPUS_API_URL`.

Для локального теста Mini App, открываемого с HTTPS GitHub Pages или из Telegram, браузеру нужен доступный HTTPS-адрес backend. Адрес `http://localhost:8080` на компьютере пользователя не указывает на твой ноутбук, а браузеры блокируют смешанный HTTP-контент из HTTPS-страницы. Поэтому локальный Telegram-тест Mini App требует временного HTTPS-туннеля или отдельного HTTPS-хоста. Сам Telegram-бот можно проверять локально без публикации backend, если ноутбук и сеть доступны.

CORS должен содержать только origin сайта, например `https://dewut.github.io` — без пути репозитория и `/miniapp/`. Telegram Mini App должен открываться по HTTPS. Backend проверяет подписанный `Telegram.WebApp.initData`; не передавай Telegram ID как замену проверке подписи.

## Проверки после локального запуска

### HTTP и база
- Открой `http://127.0.0.1:8080/health`.
- При доступной Neon ожидается JSON со `status: "ok"` и `database: "ok"`.
- При недоступной Neon ожидается HTTP 503, а не ложный успешный health check.
- В логах проверь успешное применение миграций и запуск API.

### Mini App → Neon → Telegram bot
- Открой Mini App из личного чата бота через HTTPS URL.
- В «Настройки → Личное» измени интервал напоминания, сохрани, перезапусти Mini App и проверь загрузку значения.
- Для теста включи дайджест только на тестовом аккаунте и проверь часовой пояс Москва.

### Групповые настройки и права
- Добавь бота в тестовую Telegram-группу и назначь администратором.
- Выполни `/setgroup` и `/chat_settings`, чтобы backend получил актуальные сведения о чате.
- В Mini App проверь, что изменять настройки могут только пользователи, чьи права подтверждены через Telegram.
- Проверь независимую доставку расписания, дайджеста и уведомлений об изменениях, а также настройки ДЗ, экзаменов, мероприятий и контекстного помощника.
- Включение контекста требует отдельного информированного согласия участников; согласие не должно сбрасываться при сохранении других настроек.

### Реальная доставка уведомлений
- В Mini App отправь тестовое уведомление себе и проверь запись `manual_test / sent`.
- Проверь heartbeat фонового цикла и отсутствие ошибок в логах.
- Для групповых уведомлений создай отдельные тестовые настройки с ближайшим временем доставки.

## Что пока требует Telegram-чата

Некоторые действия требуют исходного Telegram-сообщения или Telegram-вложения: модерация ответом на сообщение, загрузка/прикрепление файлов к ДЗ, native poll и часть операций управления участниками. Для них Mini App направляет пользователя в Telegram; это не должно имитироваться фиктивными кнопками.

## Контекстный помощник

Помощник Mini App использует локальный классификатор намерений и функции проекта: расписание, следующую пару, домашние задания, дедлайны, преподавателей и аудитории. Он не отправляет запросы внешним AI API. В Neon сохраняются только распознанные учебные обмены, максимум 24 записи на пользователя и 7 дней хранения. Обычные вопросы и личные сообщения без учебного намерения в историю не записываются.
