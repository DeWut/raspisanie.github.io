# Telegram bot — отдельная рабочая ветка

Рабочая ветка: `work/telegram-bot`

Базовая точка ответвления: `feature/campus-map-photorealism` (снимок на момент создания ветки).

## Что относится к боту

- `backend/src/bot.rs` — команды, клавиатуры, обработчики Telegram, напоминания и модерация.
- `backend/src/main.rs` — запуск long polling бота вместе с HTTP API.
- `backend/src/config.rs` — настройки окружения бота.
- `backend/migrations/*telegram*` и миграции ролей/чатов — таблицы и изменения схемы, используемые ботом.
- Связанные backend-модули и сервисы, если они нужны командам бота: расписание, группы, роли, контент.

## Как запускать

Из каталога `backend/`:

```bash
cp .env.example .env
# Заполнить DATABASE_URL и TELOXIDE_TOKEN; ADMIN_TELEGRAM_ID.
cargo run --bin smart-campus-backend
```

Backend запускает HTTP API, SQLx migrations, синхронизацию расписания и Telegram long polling в одном процессе. Это важно: бот сейчас не является отдельным бинарным сервисом и использует общие модели, БД и состояние приложения.

## Проверки

```bash
cd backend
cargo fmt --check
cargo check
cargo test
```

Запуск требует PostgreSQL 16 с расширениями `vector` и `pg_trgm`. Не добавлять `.env`, токены Telegram, DATABASE_URL и реальные секреты в Git.

## Правила изменений

1. Не менять `miniapp/**` в этой ветке, если изменение не является согласованным контрактом между ботом и Mini App.
2. Не удалять и не переписывать применённые миграции. Новые изменения схемы — только новой миграцией.
3. Изменения API/формата данных, используемые Mini App, согласовывать с `work/telegram-miniapp`.
4. Для включения в общую линию создавать PR в `feature/campus-map-photorealism`, предварительно обновив ветку и проверив конфликтующие миграции.
5. Не мержить эту ветку напрямую в `main` без отдельной проверки интеграции.

## Связь с Mini App

Mini App находится в `miniapp/` и публикуется как статические файлы. Сейчас она в основном читает расписание из `data/` и может работать без backend API URL. Кнопка запуска Mini App формируется ботом из HTTPS `WEBAPP_URL`. Не считать бот и Mini App независимыми по контракту только потому, что у них отдельные Git-ветки.
