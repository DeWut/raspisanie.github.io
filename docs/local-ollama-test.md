# Локальная LLM для тестирования Smart Campus

Эта схема не требует банковской карты или платного AI API. Для первого теста проще запустить и Ollama, и Rust backend на одном ПК — инструкция: [docs/local-backend-test.md](local-backend-test.md). Если backend уже размещён на Render, используй описанный ниже защищённый proxy и Funnel.

## Ресурсы компьютера

32 ГБ RAM достаточно для тестирования Qwen 3 8B в квантовании Q4. Сначала используем CPU/GPU автоматически через Ollama. Модель можно хранить на внешнем диске, но HDD будет заметно медленнее SSD. Внешний диск нужен для свободного места, не для увеличения RAM.

## Установка на Windows (режим Render + локальная модель)

1. Установить Ollama: https://ollama.com/download/windows
2. Установить Python 3.11+ (если ещё не установлен).
3. (Необязательно) Чтобы хранить веса на внешнем диске, создай на нём постоянную папку, например `E:\OllamaModels`, задай пользовательскую переменную Windows `OLLAMA_MODELS` с этим путём и полностью перезапусти Ollama. Буква диска должна оставаться постоянной; отключать диск во время работы нельзя. Официальная инструкция: https://github.com/ollama/ollama/blob/main/docs/windows.mdx.
4. Установить Tailscale: https://tailscale.com/download/windows и войти в аккаунт.
5. Открыть PowerShell в корне репозитория и выполнить:

```powershell
ollama pull qwen3:8b
$env:OLLAMA_PROXY_TOKEN = [guid]::NewGuid().ToString("N") + [guid]::NewGuid().ToString("N")
Write-Host "Сохрани этот секрет в Render как OLLAMA_API_KEY: $env:OLLAMA_PROXY_TOKEN"
python .\scripts\ollama_proxy.py
```

Команда выведет случайный секрет в переменную текущего окна PowerShell. Сохрани его в менеджере паролей; не отправляй в чат и не коммить в GitHub. Окно proxy должно оставаться открытым. Ollama Desktop обычно запускает локальный сервер автоматически; если нет, запусти `ollama serve` в отдельном окне.

6. В другом PowerShell окне запусти Funnel:

```powershell
tailscale funnel --bg 11435
tailscale funnel status
```

Tailscale покажет публичный HTTPS URL вида `https://имя-устройства.<tailnet>.ts.net`. Если Funnel просит включить его в админ-панели Tailscale, выполни это. У Funnel есть ограничения тарифного плана и доступности; если команда не сработает, не открывай порты роутера и не публикуй 11434.

## Переменные Render (только если backend запущен на Render)

В настройках сервиса backend добавь:

- `OLLAMA_BASE_URL` — URL Funnel без завершающего слеша, например `https://имя-устройства.<tailnet>.ts.net`.
- `OLLAMA_API_KEY` — значение `OLLAMA_PROXY_TOKEN` из PowerShell.
- `OLLAMA_MODEL` — `qwen3:8b`.

Не добавляй токен в репозиторий, исходники Mini App или публичные сообщения.

## Проверка

Открой `https://имя-устройства.<tailnet>.ts.net/health`: должен вернуться JSON с `"ok": true`. Этот endpoint не требует токен, но не раскрывает состояние модели. Запросы к `/api/chat` без корректного Bearer-токена должны получать 401.

Если компьютер выключен, ушёл в сон или потерял интернет, модель будет недоступна. Backend обязан переключаться на локальные правила и не зависать в ожидании. Для публичного постоянного использования это пока тестовая архитектура, не SLA.

## Важно о Render

Render Free действительно позволяет создавать бесплатный Web Service без обязательной оплаты. Официальная инструкция говорит, что для первого бесплатного деплоя оплата не требуется. Однако конкретные шаги в интерфейсе аккаунта могут отличаться; если Render требует карту, не выбирай платный план и не добавляй чужую карту. См. https://render.com/docs/your-first-deploy и https://render.com/docs/free.
